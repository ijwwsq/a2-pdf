# a2pdf — фронтенд

## Что это за сервис

Внутренний инструмент: сотрудник даёт документ в любом удобном виде, получает
PDF в фирменном оформлении A2DATA — с обложкой, колонтитулами, нумерацией
страниц, диаграммами и встроенными шрифтами.

Источник может быть трёх видов:

1. **файл** `.md`, `.markdown` или `.docx` (до 20 МБ);
2. **текст** — markdown, вставленный прямо в окно;
3. **ссылка** — страница Notion (`notion.so`, `notion.site`, `app.notion.com`),
   обычная веб-страница или прямая ссылка на `.md`.

Оформление исходника игнорируется: документ пересобирается по брендбуку.
Из содержимого переносятся заголовки, абзацы, списки, таблицы, код, цитаты,
картинки и диаграммы mermaid.

Кто пользуется: менеджеры и аналитики, которые готовят коммерческие
предложения, отчёты и внутренние документы. Частота — несколько раз в день,
поэтому важнее всего скорость до результата: минимум полей, разумные значения
по умолчанию, сразу видимый результат.

## Как устроен фронт

Одна страница, которую отдаёт сам сервис по `GET /`. Никакой сборки, никаких
внешних CDN: один `index.html` со встроенными стилями и скриптом. Шрифты
приходят с того же адреса — `/fonts.css` (Inter и JetBrains Mono, встроены
в base64).

Ограничения, которые нельзя нарушать:

- ни одного запроса на сторонние домены — сервис работает во внутренней сети;
- вся логика — на обычном JS без фреймворков и сборщиков;
- контракт полей формы менять нельзя (см. раздел «API»), верстка меняется
  свободно.

## Экран

Рабочий стол в две колонки: слева ввод и настройки, справа предпросмотр
результата. На узких экранах — одна колонка, предпросмотр уходит вниз.

```
┌──────────────────────────────────────────────────────────┐
│ Шапка: логотип · подпись                                 │
├──────────────────────┬───────────────────────────────────┤
│ Панель «Источник»    │                                   │
│  · три вкладки       │  Панель предпросмотра             │
│  · зона ввода        │   · имя файла, размер             │
│                      │   · кнопки «Открыть», «Скачать»   │
│ Панель «Шаблон»      │   · страница PDF                  │
│  · карточки          │   · пустое состояние до сборки    │
│  · настройки         │                                   │
│  · кнопка сборки     │                                   │
├──────────────────────┴───────────────────────────────────┤
│ Подвал                                                   │
└──────────────────────────────────────────────────────────┘
```

## Блоки и состояния

### Шапка

Тёмно-синяя полоса, снизу янтарная линия 3 px. Слева вордмарк `A2DATA`
(`A2` белым, `DATA` — фирменным голубым), справа мелкая подпись моноширинным
шрифтом.

### Источник

Сегментированный переключатель на три вкладки: **Файл**, **Текст**, **Ссылка**,
у каждой иконка. Активная вкладка — белая плашка с тенью на сером фоне группы.

Высота области ввода одинаковая у всех трёх вкладок: при переключении страница
не должна дёргаться.

| Вкладка | Содержимое |
|---|---|
| Файл | зона перетаскивания: иконка, «Перетащите файл сюда», подпись про форматы и лимит. После выбора — карточка с расширением, именем и крестиком. Длинное имя переносится, а не обрезается |
| Текст | многострочное поле моноширинным шрифтом с плейсхолдером-примером |
| Ссылка | однострочное поле и подсказка про доступ в Notion |

Состояния зоны перетаскивания: обычное, наведение, файл над окном (голубая
рамка и подсветка), выбран файл, ошибка формата.

### Шаблон

Сетка карточек 3 × 2. Карточка — миниатюра обложки (маленькая копия реальной
обложки: янтарный штрих, полоса заголовка, полоса подзаголовка; для шаблонов
с фото — обесцвеченный снимок под синим слоем), под ней название и короткая
подпись. Выбранная карточка выделяется рамкой.

Шаблоны и что они подставляют:

| Шаблон | Надпись | Фон | Дополнительно |
|---|---|---|---|
| Без шаблона | — | синий | ничего не заполняет |
| Коммерческое | Коммерческое предложение | фото города | реквизиты: клиент, срок, версия |
| Отчёт | Отчёт | белый | реквизиты: период, автор |
| Внутренний | Внутренний документ | синий | плашка «Конфиденциально» |
| Тестовое | Тестовое задание | абстрактное фото | реквизиты: роль, срок сдачи |
| Концепция | Концепция | фото космоса | — |

Ниже — переключатель «Оформление документа», разворачивающий блок полей.
По умолчанию блок свёрнут: большинству хватает шаблона.

### Оформление документа

Поля разбиты на группы с тонкими разделителями: «Обложка», «Фон обложки»,
«Реквизиты внизу обложки», «Колонтитулы», «Структура». Фон выбирается рядом
миниатюр (синий, белый и встроенные фото), рядом — кнопка «Своё фото».
Все поля необязательные и перекрывают то, что подставил шаблон и что нашлось
в документе.

| Поле | Тип | Заметки |
|---|---|---|
| Заголовок | текст | по умолчанию берётся из документа |
| Надпись над заголовком | текст | мелкая строка над заголовком |
| Номер | текст | «01», выводится рядом с надписью |
| Подзаголовок | текст | одна строка |
| Фон обложки | миниатюры | Синий, Белый и фото из `GET /covers` |
| Своё фото | файл | jpg, png, webp; отменяет выбранное встроенное фото |
| Плашка | текст | например «Конфиденциально» |
| Колонтитул слева | текст | запоминается между сессиями |
| Колонтитул справа | текст | запоминается между сессиями |
| Реквизиты внизу обложки | многострочное | строки вида `Ключ=Значение` |
| Обложка | флажок | включена по умолчанию |
| Нумеровать разделы | флажок | включена по умолчанию |

Запоминать в `localStorage` (ключ `a2pdf`): колонтитулы, фон обложки и выбранное
фото. Остальное — каждый раз заново.

### Формат и кнопка

Над кнопкой — переключатель формата на две позиции: **PDF** и **Word**.
Выбранный формат меняет надпись на кнопке («Собрать PDF» / «Собрать Word»)
и расширение готового файла.

Кнопка «Собрать PDF» — тёмно-синяя, неактивна, пока не выбран источник.
Рядом подсказка `Ctrl+Enter` и строка статуса. У строки статуса
фиксированная высота, чтобы блок не прыгал.

Состояния статуса: пусто, «Собираю» со спиннером, «Читаю страницу» (для
ссылки), «Готово», текст ошибки красным.

### Предпросмотр

Панель прилипает к верху экрана и занимает высоту окна. Шапка панели: имя
файла, размер моноширинным, кнопки «Открыть» (новая вкладка) и «Скачать»
(тёмно-синяя). Ниже — сам PDF в `iframe`.

До первой сборки — пустое состояние: иконка документа, «Здесь появится
документ» и строка-пояснение. Кнопки в шапке скрыты.

Word в `iframe` не показывается: вместо страницы выводится сообщение
«Документ Word готов» и предложение скачать файл. Кнопки «Открыть»
и «Скачать» работают одинаково для обоих форматов.

## API

Всё, что нужно фронту.

### `POST /convert`

`multipart/form-data`. Ровно одно из трёх полей источника:

| Поле | Тип | Описание |
|---|---|---|
| `file` | файл | `.md`, `.markdown`, `.docx` |
| `text` | строка | markdown |
| `url` | строка | ссылка на страницу |

Формат результата — поле `format`: `pdf` (по умолчанию) или `docx`.

Остальные поля необязательны: `title`, `subtitle`, `kicker`, `index`, `header`,
`footer`, `confidential`, `meta` (строки `Ключ=Значение` через перевод строки
или `;`), `style` (`dark` или `light`), `background` (имя встроенного фото),
`photo` (файл), `cover=0` (без обложки), `numbered=0` (без нумерации разделов).

Ответ — `application/pdf` с заголовком `Content-Disposition`, в нём имя файла.
Ошибки приходят как `{"detail": "текст"}` с кодами:

| Код | Когда |
|---|---|
| 400 | нет источника, пустой файл, недоступная страница, битая ссылка |
| 413 | файл или текст больше лимита |
| 415 | неподдерживаемый формат |
| 429 | превышен лимит запросов |
| 504 | сборка не уложилась в таймаут |
| 500 | внутренняя ошибка |

Текст из `detail` показываем пользователю как есть — он написан по-русски
и объясняет, что делать.

### Остальное

- `GET /covers` — `{"covers": ["abstract", "city", "space"]}`;
- `GET /covers/{имя}.jpg` — картинка для миниатюры шаблона;
- `GET /healthz` — состояние сервиса;
- `GET /fonts.css` — шрифты.

Пример запроса:

```js
const body = new FormData();
body.append('url', 'https://app.notion.com/p/...');
body.append('kicker', 'Коммерческое предложение');
body.append('style', 'dark');
const res = await fetch('/convert', { method: 'POST', body });
const blob = await res.blob();               // application/pdf
```

## Поведение

- перетаскивание файла работает над всей страницей, а не только над зоной;
  при сбросе автоматически включается вкладка «Файл»;
- если пользователь вставляет ссылку из буфера, когда фокус не в поле,
  включается вкладка «Ссылка» и адрес подставляется сам;
- `Ctrl+Enter` (и `Cmd+Enter`) запускает сборку из любого места страницы;
- имя результата: для файла — имя исходника с расширением `.pdf`, иначе —
  из `Content-Disposition`, иначе — заголовок документа;
- предыдущий `objectURL` освобождается перед новой сборкой;
- во время сборки кнопка заблокирована, повторная отправка невозможна.

## Оформление

Всё берётся из брендбука A2DATA.

| Роль | Цвет |
|---|---|
| Brand Navy | `#0B2660` |
| Brand Blue | `#1FA8FC` |
| Accent Amber | `#FF9F1C` |
| Deep Ink (текст) | `#111722` |
| Поверхности | `#FFFFFF`, `#F7F8FA`, `#EFF1F4` |
| Границы | `#E1E4EA` |
| Вторичный текст | `#6B7280`, `#9CA3AF` |

Пропорции: около 60% белого и нейтральных, 25% синего, 12% голубого, 3%
янтарного. Янтарный — акцент на одном-двух элементах: линия под шапкой
и штрих на миниатюрах обложек. Заливать им кнопки и панели нельзя.

Шрифты: Inter (400, 500, 600, 700; 800 — только вордмарк) и JetBrains Mono
для метаданных, размеров, горячих клавиш и кода. Регистр предложения везде;
ЗАГЛАВНЫЕ — только для коротких надписей с увеличенным трекингом.

Радиусы 8 / 12 / 16 px, тени мягкие сине-серые. Иконки — Tabler или Lucide,
контурные, толщина 1.5–1.7, размер 16–24, цвет наследуется от текста.

Табличные цифры включены глобально: `font-variant-numeric: tabular-nums`.

## Адаптив

| Ширина | Поведение |
|---|---|
| > 1080 px | две колонки, предпросмотр прилипает к верху |
| ≤ 1080 px | одна колонка, предпросмотр под формой, `iframe` на 70% высоты окна |
| ≤ 560 px | карточки шаблонов в два столбца, поля настроек в один |

## Доступность

- у вкладок роль `tab`, у панелей — `tabpanel`, активная вкладка помечается
  `aria-selected`;
- видимый фокус у всех интерактивных элементов (голубая рамка);
- у `iframe` предпросмотра и иконок — понятные подписи;
- вся форма проходится с клавиатуры, порядок табуляции сверху вниз.

## Чего делать не нужно

- подключать шрифты, иконки или скрипты с внешних адресов;
- добавлять анимации сложнее плавной смены цвета и спиннера;
- показывать технические подробности ошибок — только текст из `detail`;
- заменять янтарным основной цвет кнопок и панелей;
- прятать предпросмотр за отдельным экраном: результат должен быть виден
  сразу после сборки.

## Приёмка

- [ ] переключение вкладок не меняет высоту страницы;
- [ ] длинное имя файла переносится и не ломает карточку;
- [ ] шаблон подставляет надпись, фон и реквизиты, выбранная карточка выделена;
- [ ] блок «Оформление документа» свёрнут по умолчанию, разворачивается одним кликом;
- [ ] выбранный фон подсвечен, шаблон переключает его сам;
- [ ] колонтитулы и фон восстанавливаются после перезагрузки страницы;
- [ ] ошибка сервиса видна в строке статуса и не ломает форму;
- [ ] после сборки PDF открывается в правой панели, кнопки «Открыть»
      и «Скачать» работают;
- [ ] при выборе Word кнопка меняет надпись, а в панели предпросмотра
      появляется сообщение о готовом файле;
- [ ] на ширине 1024 и 480 px верстка не разъезжается;
- [ ] в консоли нет запросов на внешние домены.
